# Mise

## Commands

Dont forget this commands

- [mise backends switch](https://mise.jdx.dev/cli/backends/switch.html#mise-backends-switch)
  - -g --global
  - -n --dry-run
  - \[TOOL@VERSION\]… — Tools to switch

- [mise ls](https://mise.jdx.dev/cli/ls.html#mise-ls)
  - --grouped — List tools in a separate section for each backend
  - -i --installed — Only show installed versions
