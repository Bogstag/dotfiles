## Hunspell

Install from pacman.

Copy files to my dicts.

```sh
cp --force /usr/share/hunspell/en_GB-large.aff $HOME/.config/Dictionaries/
cp --force /usr/share/hunspell/en_GB-large.dic $HOME/.config/Dictionaries/
cp --force /usr/share/hunspell/en_US-large.aff $HOME/.config/Dictionaries/
cp --force /usr/share/hunspell/en_US-large.dic $HOME/.config/Dictionaries/
```
